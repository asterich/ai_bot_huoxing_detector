不包含真实 QQ 账号、NapCat 在线接入、真实群图片数据集评测或不同版本 AstrBot/MaiBot 的端到端测试。也不声称所有 GCC 高版本或 Clang 高版本都已测试；CMake 允许 GCC >=16.1、Clang >=21，当前实测版本如表。
