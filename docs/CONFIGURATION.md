# AstrBot 火星检测配置

安装包含 `_conf_schema.json` 的新版插件后，在 AstrBot WebUI 的插件管理中打开 `astrbot_plugin_huoxing` 的配置。修改、保存后重载插件（或重启 AstrBot）生效。配置由 AstrBot 保存到 `data/config/astrbot_plugin_huoxing_config.json`，更新插件不应覆盖该文件。

## 个人触发限频

| 配置项 | 默认值 | 含义 |
| --- | --- | --- |
| `trigger_window_seconds` | 180 | 滚动统计窗口，单位秒 |
| `trigger_image_count` | 3 | 窗口内累计触发的火星图片数 |
| `sender_pause_seconds` | 600 | 达到阈值后暂停此人的检测时长，单位秒 |
| `same_image_cooldown_seconds` | 60 | 相同图片证据或拒绝原因的缓存时间，单位秒 |
| `reply_cooldown_seconds` | 30 | 每群两次提醒之间的最短间隔，单位秒 |

例如某人于 12:00、12:01、12:02 各发一张火星图片，第三张触发后，至 12:12 暂停对此人的检测。按机器人账号、群号、发送者分别统计，不影响同群其他人或其他群。第三张仍可正常提醒；是否发送取决于群提醒冷却。

统计对象是**触发火星的图片**，不是所有消息，也不是提醒条数。同一消息中的多张火星图分别计数；同一张图的再次发送即使命中缓存仍计数；宿主重放同一消息不重复计数。普通新图片、表情包、HDR、动图、无效图片、卡片和合并转发均不累计图片触发次数。达到阈值立即停止当前消息的剩余检查，暂停期间跳过此人的所有火星检测，包括卡片和合并转发。

暂停检查发生在构造/下载图片之前。暂停期间的消息不入库、不排队补查，也不延长暂停；到期后从空窗口重新统计。窗口或暂停时长设为 0 可关闭个人暂停规则。图片数范围 1–1000；所有时间参数范围 0–86400 秒。

首次图片正常入库，第一次重复正常检测；其后的短时重复复用首次消息和识别依据。相同源可以免下载；源变化而文件字节相同时，需读取文件后按 SHA-256 跳过解码和 C++ 查重。不同编码、裁剪等视觉变体仍交给原生识别。缓存为 0 时每次正常检测。缓存命中的重复不会再写入每次发送的原生记录。

同时最多处理一个事件，覆盖下载、文件读取、解码和原生计算；忙时直接跳过，不创建等待队列。所有限频及缓存状态有容量上限，保存在内存中，重载插件或重启后清空。重载前后的历史图片数据库保留。

## 提醒文案

图片、合并转发、分享卡片分别设置 `image_reply_template`、`forward_reply_template`、`card_reply_template`。支持 `{first_message_id}`、`{first_seen}`、`{method}`；例如：

```text
火星了！第一次出现：{first_message_id}，依据：{method}
```

文案不必包含占位符；`{{`、`}}` 输出字面大括号。图片可使用全部字段；卡片和转发只保证首次消息 ID，其他字段可能为空。模板最长 2000 字，不能为空。无效模板或数值会明确记录配置名与原因，并回退到该项默认值。

## 图片限制

`max_image_mib` 默认 8 MiB，`max_image_megapixels` 默认 16（1600 万像素）；两项范围均为 0.1–32。文件读取和解码执行同一个文件大小限制；像素限制在分配 RGBA 像素缓冲前检查。只改变当前插件 Detector 实例，不修改其他宿主的进程全局限制。文件过大、像素过多的日志包含实际值与配置上限，不自动缩图。

**表情包、带 HDR 增益图的照片、动图强制跳过，没有配置开关。** 表情包在消息分类时就被排除，不构造图片或下载。HDR/动图从图片元数据识别，因而通常需要取得文件；HDR 标记检测覆盖 Apple/Adobe/ISO 增益图标记，不能承诺识别所有 HDR 编码。多图像文件也继续拒绝，不自动只取首帧。
